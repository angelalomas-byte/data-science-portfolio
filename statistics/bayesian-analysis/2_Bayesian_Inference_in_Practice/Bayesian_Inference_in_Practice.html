Bayesian Modeling of Enrollment, Interest, and AI Usage: A Beta–Binomial and Poisson–Gamma Approach

Author

Ángela Lomas Anglada

Introducción

El objetivo de nuestro trabajo es realizar un estudio bayesiano combinando información a priori (creencias razonadas antes de ver los datos) y datos actuales obtenidos tras una encuesta a la clase de 4º curso de Ciencia de Datos.

Primero, definimos nuestras creencias o estimaciones iniciales sobre cada pregunta de la encuesta, que constituyen la información a priori. A continuación, mediante la encuesta recogimos datos actuales de los estudiantes, que utilizamos para actualizar nuestras creencias y calcular la probabilidad a posteriori.

A partir de estas distribuciones posteriores, pudimos extraer conclusiones sobre el comportamiento y las características de los estudiantes, y además predecir aproximadamente cuántos se matricularán en la asignatura el próximo año.

Descripción de la encuesta

La encuesta constaba de cuatro preguntas principales:

  • ¿Estás matriculado en la Optativa de Análisis Bayesianos? (Sí/No): permite identificar qué estudiantes forman parte del grupo objetivo.

  • Para matriculados, ¿era vuestra primera opción? (Sí/No): solo se responde si el estudiante está matriculado.

  • ¿Te interesa aprender más sobre un enfoque bayesiano en análisis de datos? (1–5): evalúa el nivel de interés de los estudiantes.

  • Número de veces promedio que te metes en ChatGPT en un día normal (0–10 o más): mide el uso de herramientas de IA.

Creencias a priori sobre las preguntas

Antes de analizar los datos recogidos, definimos nuestras creencias a priori para cada pregunta:

  • Pregunta 1 (matriculados en la asignatura): estimaciones de Paco (15/50), Marta (9/50) y Ángela (13/50), con creencia promedio p=0.2467.

  • Pregunta 2 (primera opción): decidimos usar una prior no informativa, al no contar con información previa.

  • Pregunta 3 (interés por Bayes): creencias de Paco (4), Marta (2) y Ángela (3), con creencia promedio 3.

  • Pregunta 4 (uso de ChatGPT): mismas estimaciones que la pregunta 1, con creencia promedio p=0.2467

Con estas priors y los datos recogidos, aplicaremos modelos bayesiando con el objetivo de obtener las distribuciones a posteriori posibles y hacer predicciones sobre el número de matriculados y las características de los estudiantes el próximo año, incorporando la incertidumbre de manera bayesiana.

PREGUNTA 1:

Nosotros hemos ofrecido unas estimaciones previas sobre cuántos estudiantes esperábamos que estuvieran matriculados. La media de estas creencias es de p = 0.2467. Para construir un priori Beta adecuado, debemos de transformar la probabilidad en ‘casos iamginarios’ de éxitos y fracasos. Los éxitos serían 13 y los fracasos 37. Usamos α + β = 10 porque da una prior moderada, que refleja las estimaciones previas sin dominar los datos.

p ∼Beta( α = 2.6, β =7.4)

PREGUNTA 2:

No contábamos con infroamción previa clara sobre la probabilidad de que un estudiante matriculado tuviera la asignatura como primera opción, decidiendo usar prior no informativa, asignando la misma probabilidad a cualquier valor de p entre 0 y 1.

p ∼ Beta(1,1)

Añadid una frase breve explicando por qué α y β deben ser números > 0 y representar pseudo-casos.

PREGUNTA 3:

La escala 1–5 no se puede modelar directamente con una Beta, por lo que transformamos la variable en interés-alto (≥3) para poder usar un modelo Beta–Binomial. Como las opiniones previas eran ordinales y no se pueden convertir de forma consistente en éxitos/fracasos, usamos una prior Beta(1,1).

p ∼ Beta(1,1)

PREGUNTA 4:

Estamos frente a una variable de conteo, que modelamos medinate una distribución Poisson con parámetro L. Para construir el prior, partimos de la misma creencia previa que en la pregunta 1, interpretamos el valor como la fracción aproximada del rango máximo (0–10).

λ prior​≈0.2467×10=2.467

λ∼Gamma(α =2.467,β =1)

Modelos Bayesianos

Aplicamos modelos bayesianos para estimar las distribuciones a posteriori de cada variable, usando Beta–Binomial para proporciones y Poisson–Gamma para conteos.

1- Beta-Binomial

La media, mediana y moda posteriores (≈0.25) son muy similares, lo que indica que la distribución posterior es bastante estable y con poca asimetría.

Esto sugiere que la asignatura atrae a una minoría significativa, pero no despreciable, dentro del conjunto de estudiantes.

# PREGUNTA 3: Interés (1-5)

# El interés está medido en una escala ordinal del 1 al 5. 
# Este tipo de variable NO es un conteo (como requiere Poisson),
# ni representa directamente una proporción de éxitos/fracasos.
# Por este motivo, NO puede modelarse con Poisson-Gamma.

# Para aplicar un modelo conjugado necesitamos una variable binaria.
# Por eso la transformamos a:
#     interes_alto = 1 si interés >= 3
#     interes_alto = 0 si interés < 3
# Así podemos modelar p = P(interés alto) con un modelo Beta-Binomial.

df$interes_alto <- ifelse(df$interes >= 3, 1, 0)

# SOBRE LA PRIOR:
# Aunque teníamos creencias previas de Paco (4), Marta (2) y Ángela (3),
# estos valores están en una escala ordinal y NO representan frecuencias
# ni proporciones. 
#
# La media 3 tampoco sirve para construir una prior Beta porque:
# - una media no determina cuántos estarían con interés >= 3,
# - muchas distribuciones ordinales distintas tienen la misma media,
# - por ejemplo: (5,1), (3,3), (4,2) todas tienen media 3 pero producen
#   probabilidades completamente distintas para interés>=3.
#
# Por tanto, NO existe una forma coherente de convertir los valores 
# (4,2,3) en "éxitos previos" y "fracasos previos" para una Beta(α,β).
#
# En ausencia de información previa válida para p = P(interés alto),
# usamos una prior NO informativa:
#           p ~ Beta(1,1)
# que es uniforme en [0,1] y no favorece ningún valor.

alpha3 <- 1
beta3  <- 1

cat("Prior P3 = Beta(1,1)\n")
Prior P3 = Beta(1,1)
# Datos
x3 <- sum(df$interes_alto == 1)
n3 <- length(df$interes_alto)

# Posterior (modelo Beta-Binomial)
alpha_post3 <- alpha3 + x3
beta_post3  <- beta3  + (n3 - x3)

cat("Posterior P3 = Beta(", alpha_post3, ",", beta_post3, ")\n")
Posterior P3 = Beta( 26 , 7 )
# Estadísticos posteriores
post_mean3   <- alpha_post3 / (alpha_post3 + beta_post3)
post_mode3   <- (alpha_post3 - 1) / (alpha_post3 + beta_post3 - 2)
post_median3 <- qbeta(0.5, alpha_post3, beta_post3)
