# Bayesian Analysis

This folder contains selected projects developed in the Bayesian Analysis course, focused on statistical inference under uncertainty and its applications in Data Science and Machine Learning.

The course provided a rigorous and applied introduction to the Bayesian paradigm, combining theoretical foundations with practical implementation in R.

## Course Focus

The main objective was to understand and apply Bayesian methods for inference, prediction, and decision-making in uncertain environments.

Key areas covered:

- Foundations of Bayesian Statistics
- Bayesian inference with unknown parameters
  - Proportion models (Binomial–Beta)
  - Gaussian models with conjugate priors
- Posterior distribution analysis
- Predictive distributions
- Bayesian Networks
- Bayesian Networks for supervised classification
- Naive Bayes classifier

## Skills Demonstrated

Through the projects in this section, I developed the ability to:

- Translate real-world problems into probabilistic models
- Perform Bayesian parameter estimation
- Interpret posterior distributions and credible intervals
- Implement Bayesian inference computationally in R
- Apply Bayesian Networks for classification tasks
- Compare models and evaluate predictive performance

- R

- Bayesian inference
